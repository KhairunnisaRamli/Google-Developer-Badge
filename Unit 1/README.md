# 🚀 Unit 1: Your First Android App

Welcome! 👋 This folder holds my work for **Unit 1: Your First Android App**, the first step in my individual Android development portfolio.

This unit has three pathways: **Introduction to Kotlin**, **Setup Android Studio**, and **Build a Basic Layout**. It took me around 10 hours in total, and it gave me the foundation for everything that comes next in my Android journey. 🎯

---

## 🧠 Pathway 1: Introduction to Kotlin
This is where it all began! I wrote my first Kotlin programs that print text to the console. 💬

**What I learned:**
- ✏️ Basic Kotlin syntax, including variables, data types, and functions
- 🖨️ How to use `println()` to display text in the console
- 📱 Why Kotlin is such an important language for modern Android development

**Outcome:**
I now understand the Kotlin fundamentals, and I'm ready to use them with Android SDK components. ✅

---

## 🛠️ Pathway 2: Setup Android Studio
Time to get my workspace ready! I downloaded and configured **Android Studio**, the official IDE for building Android apps.

**Key learning points:**
- ⚙️ How to install and configure Android Studio
- 🧩 How the Gradle build system and basic Android project structure work
- ▶️ How to run a "Hello World" app on an Android emulator

**Outcome:**
I built my very first Android project! 🎉 I also got comfortable with building, running, and testing apps in Android Studio.

---

## 🎨 Pathway 3: Build a Basic Layout
Here's where things got visual! I built an app with a simple interface that shows both text and images. 🖼️

**What I explored:**
- 📄 XML layout files and how they structure the user interface
- 🔤 Using `TextView` to display text and `ImageView` to show images
- 📐 Choosing layouts like `LinearLayout` to arrange UI components

**Outcome:**
I created a simple app that combines text and images, proving I can design and organize a basic Android interface. ✨

---

## 💭 Reflection
Finishing Unit 1 helped me:
- 🌱 Grow from learning basic Kotlin concepts to actually using them in Android Studio
- 🔗 See how Kotlin code and XML layouts work together in an Android app
- 💪 Build confidence in setting up my development environment and making my first app

**😅 Challenges I faced:**
- Setting up the emulator took some troubleshooting
- The structure and hierarchy of XML needed lots of practice
- Connecting Kotlin code to the UI components was tricky at first

**🤔 Choices I made:**
- I picked `LinearLayout` because it was simple to understand and implement
- I added a custom image to make the app feel more personal
- I chose Kotlin because it supports modern Android development practices
