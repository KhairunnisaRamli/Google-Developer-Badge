# 💭 Reflection - Unit 2: Building App UI

## 🧠 What I Learned
- 🔀 How to use conditionals, classes, function types, and lambda expressions in Kotlin
- 👆 How apps can respond to user interactions, such as button clicks
- 🔄 How state can be managed to calculate and update values, like in a tip calculator

## 😅 Challenges
- ⚡ Lambda expressions and function types took extra practice to click

- 🔗 Connecting programming logic to user interface behavior was a brand new experience

## 🤔 My Choices
- 🖱️ I created Kotlin-based simulations for button clicks and state management to strengthen my logic outside Android Studio
- 💰 I used simple examples, like score evaluation and a tip calculator, to help me understand the fundamentals
- 🧹 I kept my code clear and organized with readable structures and helpful comments

## 🏆 Outcome
Unit 2 strengthened my Kotlin fundamentals and introduced me to the ideas behind interactive apps. 🎉

The activities didn't fully use the Android Studio interface, but I still practiced the logic behind button interactions and state management. That prepares me for building more complete apps in the later units. On to Unit 3! 🚀
