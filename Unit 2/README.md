# 🎨 Unit 2: Building App UI

Welcome back! 👋 This folder holds my work for **Unit 2: Building App UI**, another step in my individual Android development portfolio.

This unit has three pathways: **Kotlin Fundamentals**, **Add a Button to an App**, and **Interacting with UI and State**. It took me around 21 hours, and it focused on building interactive apps with Kotlin. 🎯

---

## 🧠 Pathway 1: Kotlin Fundamentals
Time to level up my Kotlin! 💪 In this pathway, I deepened my understanding of the language.

**What I learned:**
- 🔀 How to use conditionals (`if`, `else`) to control the flow of a program
- ⚡ How to use function types and lambda expressions for more concise code
- 🧱 Object-oriented programming concepts, including classes, objects, and methods

**Outcome:**
I feel much more confident writing complex Kotlin programs, and I can see how these concepts apply to Android app logic. ✅

---

## 👆 Pathway 2: Add a Button to an App
Here I explored how apps respond to what users do. 🖱️

**What I explored:**
- 📡 The basic principles of event handling
- ⚙️ Writing logic that runs when a user clicks a button
- 🧪 Practicing that logic by simulating button clicks in Kotlin

**Outcome:**
I now understand how user interactions drive app behavior. 🎉 Even without the Android Studio interface, I practiced button click simulations and learned how event listeners work.

---

## 💰 Pathway 3: Interacting with UI and State
This is where I built the logic for a **Tip Calculator** app! 🧮

**What I worked on:**
- ⌨️ Receiving user input such as the bill amount and tip percentage
- 🔄 Managing state to calculate and update different values
- 📊 Displaying the results, including the tip amount and total bill

**Outcome:**
I gained hands-on experience with state management and saw how apps update their interfaces based on user input. ✨ This pathway helped me connect Kotlin logic with dynamic user interfaces.
