# 🎨 Unit 3: Display Lists and Use Material Design

Welcome back! 👋 This folder holds my work for **Unit 3: Display Lists and Use Material Design**, another step in my Android development portfolio.

This unit has three pathways: **More Kotlin Fundamentals**, **Build a Scrollable List**, and **Build Beautiful Apps with Material Design**. It took me around 15 hours, and it focused on lists, user interactions, and modern interface design. 🎯

---

## 🧠 Pathway 1: More Kotlin Fundamentals
Time to work with real data! 📦

**What I learned:**
- 🧱 How to use **data classes** to organize and represent structured information
- 📚 How to work with **collections**, including lists, filters, and maps
- ⚙️ How to write functions that process, organize, and display different types of data

**Outcome:**
I got better at representing and managing complex data in Kotlin, which is essential for apps that display lists of information. ✅

## 📜 Pathway 2: Build a Scrollable List
Here I explored how lists work behind the scenes. 🖱️

**What I practiced:**
- 🖼️ Creating lists with different items, including text and images
- 💻 Simulating a scrollable list through Kotlin console output
- 👆 Implementing **click listeners** to handle and respond to user interactions

**Outcome:**
I understand the logic behind scrollable lists and user interactions much better now. 🎉 That prepares me to work with Android components like RecyclerView and Jetpack Compose.

**What I explored:**
